## Featured Enterprise Projects

### 1. Tickora — Enterprise Multi-Agent AI Assistant
- Independently built an async conversational AI backend using **FastAPI**, **LangGraph**, and **LangChain** integrated with an Angular web app.
- Designed a multi-agent workflow routing user queries across Policy RAG, Live Data APIs, Leave Actions, and Greetings.
- Built ReAct agents with **17 custom API tools** to fetch live attendance, punch logs, and payroll data via a Java Spring Cloud Gateway, secured with **JWT and RBAC**.
- Implemented enterprise **RAG** using **PostgreSQL (pgvector)** and Gemini embeddings, with **Groq (Llama 3)** as the primary LLM, **Google Gemini** as fallback, and **Redis** for 48-hour chat memory.
- Evaluated local models (**Rasa, Qwen2.5, ONNX, Gemma 3**) under a 4 GB RAM limit to control latency and hallucinations.

**Tech Stack:** `Python` `FastAPI` `LangGraph` `LangChain` `PostgreSQL (pgvector)` `Redis` `Groq` `Gemini API` `Docker`

### 2. Tickora — Real-Time AI Face Recognition API
- Built and deployed a real-time REST API supporting 3-angle face registration, 1:1 verification, and 1:N identification using **InsightFace (ArcFace)** (99.8% LFW benchmark accuracy).
- Integrated **FAISS** vector search across **100K+ user face embeddings** for sub-second identification, serving a Java backend and Flutter mobile app.
- Set up a multi-tenant **PostgreSQL** architecture with per-organization schema isolation and SQL injection prevention to protect client data.
- Added **Redis** caching (7-day TTL) with schema-prefixed keys, cutting database verification lookups by **~80%**.

**Tech Stack:** `Python` `FastAPI` `InsightFace` `FAISS` `PostgreSQL` `Redis` `SQLAlchemy` `OpenCV` `Docker`
